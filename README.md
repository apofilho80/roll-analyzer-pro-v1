# Roll Analyzer PRO V1

Roll Analyzer PRO V1 is a Streamlit application for evaluating and comparing options roll adjustments.

## Main features

- Analyze bull put spread rolls
- Compare up to five roll candidates
- Calculate total accumulated credit
- Calculate new break-even
- Measure break-even improvement
- Compare maximum profit and maximum loss
- Estimate probability of profit
- Calculate return on risk
- Display expiration payoff charts
- Perform scenario analysis
- Generate a Professional Roll Score from 0 to 100
- Export results to CSV
